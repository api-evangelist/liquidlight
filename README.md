# LiquidLight

LiquidLight, Inc. (Liquid Light) was an electrochemistry company in Monmouth Junction, New Jersey that
developed and licensed process technology for converting carbon dioxide into industrial chemicals —
monoethylene glycol (MEG), propylene and acetic acid — from technology licensed out of Princeton
University. Founded in 2009, it raised seed funding from Redpoint Ventures and a $15M Series B in 2014
from VantagePoint Capital Partners and BP Ventures, and was a Battery Ventures portfolio investment.

**Status: acquired.** Avantium acquired Liquid Light on January 10, 2017 and the company no longer
operates independently.

**No API surface.** LiquidLight was a materials and process-technology company. It never published a
public API, developer portal, SDKs, or any machine-readable developer surface, and no company web
property survived the acquisition. This repository is kept as an accurate non-API portfolio record;
the enrichment pipeline correctly produced no API artifacts rather than fabricating any.
